プロジェクト名：ブロック崩し(burokkukuzusi)

概要

古典的なアーケードゲーム「ブロック崩し」
をC言語で実装したコンソールゲーム。
ボールの物理（単純な反射）、パドル操作、ブロック破壊
の基本を実装しています。
進行状況(各工程)ごとにファイルを分けてプログラムを作っています。
Windows のコンソールで動作確認済み。


動機

ゲーム開発の基礎（ループ、入力処理、描画、衝突判定）
を一通り体験するために作成。
小さなプロジェクトで「作って動かす」までを短期間で完了し、
ポートフォリオに載せられる成果を目指した。


ゲームの特徴

・パドル操作: a（左）、d（右）

・一定のFPSで動作（フレーム制御で速度安定化）

・ブロックに当たるとブロック消滅（横方向に広がる当たり判定あり）

・ライフやスコア表示は未実装（拡張の余地あり）


技術スタック

言語: C

使用ライブラリ: 標準Cライブラリ、conio.h（_kbhit/_getchを使用）

実行環境: Windows コンソール（system("cls") を使用して
　　　　　画面クリアしているためWindows向け）


実装のハイライト（技術的なポイント）

・メインループでフレームレートを固定
　
・ボールの座標を整数で管理し、壁・パドル・ブロックとの
　単純な反射を実装。

・ブロックは2次元配列 field[y][x] で管理。
　ヒットすると 0 にリセットして描画から除外。


改善点（今後の拡張案）

・描画時のフラッシュを改善。

・スコア・残機・レベル設計の追加。

・ボールの速度・反射角の改良（現在は単純な ±1 のみ）。

・ブロック種類（耐久値、スコア差）やパワーアップ実装。

学んだこと

・フレームレート固定の実装（clock() でのループ制御）。

・2D配列での衝突判定と状態管理。
